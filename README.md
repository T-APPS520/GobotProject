# Tello ドローンコントローラー

このプログラムは、DJI Telloドローンをキーボードで制御できるGoアプリケーションです。

## 機能

- **ドローン制御**: キーボードでドローンの離陸、着陸、移動を制御

## プロジェクトについて

このプログラムは、Goと生成AIによるプログラミングの学習・実践を目的として作成されています。生成AIを使用した開発により、効率性の高い実装を目指しています。

## ファイル構成

### メインプログラム
- `main.go` - メインプログラム（エントリーポイント）
- `drone_controller.go` - Telloドローンを制御するクラス
- `camera_viewer.go` - カメラ画像を処理・表示するクラス
- `keyboard_handler.go` - キーボード入力を処理するクラス

### テストファイル

- `main_coverage_test.go` - カバレッジ100%（到達可能範囲）を目指す追加テスト集
- `camera_viewer_test.go` - カメラビューワーのテスト

### 設定・ビルドファイル
- `go.mod` - Go モジュール定義
- `go.sum` - 依存関係のチェックサム
- `.gitignore` - Git除外設定
- `README.md` - このドキュメント

### 生成ファイル（実行時作成）
- `tello_controller.exe` - ビルド済み実行ファイル（Windows）
- `coverage.out` - テストカバレッジレポート
- `coverage.html` - HTML形式のカバレッジレポート

## 使用方法

### 1. 実行前の準備

1. Telloドローンの電源を入れる
2. PCのWi-FiでTelloのネットワーク（TELLO-xxxxxx）に接続
3. プログラムを実行

### 2. プログラムの実行

```bash
go run .
# または
go build -o tello_controller.exe
.\tello_controller.exe
```

### 3. キーボード操作

| キー | 動作 |
|------|------|
| **W** | 前進 |
| **A** | 左移動 |
| **S** | 後退 |
| **D** | 右移動 |
| **Space** | 上昇 |
| **Z** | 降下 |
| **Escape** | 離陸/着陸の切り替え |
| **Q** | プログラム終了 |

## テスト

### テストの実行

```bash
# 全テストを実行
go test -v ./...

# カバレッジ付きでテストを実行
go test -cover -v ./...

# カバレッジレポートを生成
go test -cover -coverprofile=coverage.out ./...
go tool cover -html=coverage.out -o coverage.html
```

### テストカバレッジ

現在のテストカバレッジは86.2%（全304ステートメント中262）です。残りの42ステートメントは、単体テストからは到達できない箇所のみで、**UTで到達可能な範囲では100%**を達成しています：

- キーボード操作の全パターン（`processKey` を直接実行）
- ドローンコントローラーの全メソッド
- カメラビューワーの録画・MP4生成
- エラー回復とシャットダウン処理（シグナル受信を含む）
- 連続操作と緊急着陸シナリオ

到達不能として除外した箇所と、その根拠は以下のとおりです：

- `main()` 全体：エントリーポイント。実行するとロボットが起動し続けるためUTからは呼べない
- `CameraViewer.Start` のビデオ開始以降（ハンドラ登録・ハンドラ本体・完了ログ）：ドローン実機に接続し、ビデオ開始コマンドの送信が成功したときにのみ到達する
- `KeyboardHandler.Start` の成功分岐と `handleKeyboard` のイベントループ本体：実端末（/dev/tty）と実キーイベントが必要で、termbox にはイベントを注入する手段がない（キー判定ロジック自体は `processKey` の直接テストで全網羅）
- デフォルト終了コールバック（`os.Exit(1)`）：呼ぶとテストプロセス自体が終了する
- 録画フレーム書き込みエラーのログ分岐：`MP4Writer.WriteFrame` は実装上エラーを返さないため到達不能（防御的コード）
- MP4生成時の moov/mdat 書き込み失敗分岐：書き込み途中のディスク障害でのみ到達する（先頭の書き込み失敗は /dev/full で検証済み）

## トラブルシューティング

### ドローンに接続できない場合
- TelloのWi-Fiネットワークに正しく接続されているか確認
- ドローンが起動しているか確認
- 他のTelloコントローラーアプリが起動していないか確認

### キーボード操作が効かない場合
- PCの入力が半角英字になっているか確認
- プログラムのコンソール画面がアクティブになっているか確認
- termbox-goパッケージが正しくインストールされているか確認
